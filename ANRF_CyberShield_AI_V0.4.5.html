Terms & Conditions

Purpose of the assessment

ANRF CyberShield AI provides an indicative assessment of an organisation's cyber security maturity against the Australian Essential Eight security strategies. The assessment is intended to improve awareness of security control gaps and provide practical improvement recommendations.

Information requested

The assessment may ask questions about application and operating-system patching practices, application control and application hardening, multi-factor authentication, Microsoft Office macro restrictions, privileged/administrative access and backup controls. Additional governance and incident-readiness questions may be included where relevant to provide context.

Accuracy of responses

Assessment results depend on the information provided by the user. Users should answer questions accurately and, where possible, verify responses with relevant technical or security personnel.

Indicative assessment only

ANRF CyberShield AI is a decision-support and cyber maturity assessment tool. It does not independently verify that security controls have been correctly implemented unless an explicit technical verification capability is provided. A favourable assessment score must not be interpreted as a guarantee that an organisation is secure or immune from cyber incidents.

Responsibility for security controls

Responsibility for selecting, implementing, operating, monitoring and maintaining cyber security controls remains with the organisation using the tool. ANRF Research and Consultancy Pty Ltd does not accept responsibility for security incidents, losses, breaches, system compromise or other consequences arising from reliance solely on this indicative assessment.

Professional advice

Recommendations are general guidance and may require further technical assessment before implementation. Organisations with sensitive, regulated, Defence-related or critical systems should seek appropriately qualified cyber security advice.

Before the assessment

How to use ANRF CyberShield AI to assess your organisation's security posture

Over the next seven assessment sections, CyberShield AI will ask you a small number of questions about how your organisation manages important cyber security controls.

Please answer in your own words and to the best of your knowledge. You do not need to use technical language. Where possible, mention the tools you use, how often activities are performed, who is responsible and how you know the control is working.

CyberShield AI will interpret the information you provide, identify areas that appear well controlled, highlight information that is missing or requires improvement, and use your responses to prepare the dashboard, recommendations and assessment report.

If you do not know an answer, simply write "I don't know". This is more useful than guessing. Do not enter passwords, credentials, classified information or other sensitive technical information.

Important: This remains an indicative self-assessment based on information supplied by the user. It does not replace technical verification or formal Essential Eight certification/assessment.

Security Control 1 of 7

Vulnerability Scanning and Patching

Patching means installing vendor updates that fix known security weaknesses in operating systems and applications. Effective vulnerability management starts with knowing what is connected to the network: automated asset discovery helps identify computers, servers and other devices, while vulnerability scanning helps identify exposed or outdated software. Timely remediation reduces the window in which known vulnerabilities can be exploited.
Describe the tool or method and, if known, what types of devices it discovers.
Include different timeframes for critical/high-risk vulnerabilities if your organisation uses them.

Security Control 2 of 7

Multi-Factor Authentication

Multi-factor authentication (MFA) requires more than one way to prove a user's identity, for example a password plus an authenticator app, security key or biometric check. MFA reduces the risk of an attacker accessing an account even if a password is stolen.

Security Control 3 of 7

Ensuring Different Access Levels

Administrator or privileged accounts can change systems, install software, access sensitive information or manage other users. Because these accounts have powerful permissions, they are attractive targets for attackers. Organisations should limit privileged access to people who genuinely need it, approve it appropriately, use it only for intended administrative duties and review it regularly.

Security Control 4 of 7

Prevent Unauthorised Software or Profiles

Application control allows approved or trusted software to run and blocks software that has not been authorised. This can help stop malware, unknown programs, scripts and unauthorised installers from executing on business devices.
Thank you. Let's now move to the next security control.
Security Control 5 of 7

Restriction of Macros

Macros are small programs embedded in documents such as Word or Excel files. Attackers can use malicious macros to run harmful code. Restricting macros, particularly those received from the internet, reduces this risk.
Thank you. Let's now move to the next security control.
Security Control 6 of 7

Securing Web Browsers and User Applications

Web browsers and commonly used applications are frequent pathways to online content and therefore need secure configuration. Application hardening reduces unnecessary or risky functionality—for example by restricting active content, unnecessary plugins and unsafe browser features, applying secure configuration standards, and keeping browsers and applications appropriately configured and updated.
Thank you. Let's now move to the next security control.
Security Control 7 of 7

Regular Backups

Backups are protected copies of important systems and data that can be restored after ransomware, accidental deletion, hardware failure or another incident. Backups should be performed regularly, protected from unauthorised changes and periodically tested to confirm that recovery actually works.
